## 📖 About This Project

This is my personal portfolio website, designed and hand-coded from the ground up.
It showcases who I am, what I can do, and the work I've built — all in a fast,
single-page, fully self-contained site hosted free on GitHub Pages.

I'm a **BS Software Engineering** student at the **University of Peshawar**, and I build
websites, edit videos, and design photos professionally.

### 🗂️ Site Sections

| Section | Description |
|---|---|
| 🏠 **Home** | Hero intro with animated typewriter headline |
| 👤 **About Me** | Who I am and what I do |
| 🛠️ **My Skills** | Web development, C++, Python, video & photo editing |
| 🎓 **My Education** | University of Peshawar, Islamia College & AMSC |
| 🗃️ **Projects** | Showcase of things I've built |
| 🛤️ **My Journey** | Career & learning timeline |
| 🤝 **Let's Connect** | GitHub and email |
| ✉️ **Contact** | Working contact form + CV download |

### ✨ Features

- 🌗 **Dark / Light theme** toggle with smooth transitions
- 📱 **Fully responsive** — mobile, tablet & desktop
- 🚀 **SEO optimized** — meta tags, Open Graph, Twitter cards, JSON-LD structured data, `robots.txt` & `sitemap.xml`
- 🎨 **Custom animations** — typing effect, scroll-reveal sections, smooth transitions
- 📄 **Downloadable CV** (`Ahmad-Ali-CV.pdf`)
- 🚧 **Custom 404 page**
- ⚡ **Zero network cost** — system font stack, all assets local

## 🚀 Run It Locally

```bash
# 1. Clone the repository
git clone https://github.com/AHMADOAFRIDI/AHMADOAFRIDI.github.io.git

# 2. Enter the folder
cd AHMADOAFRIDI.github.io

# 3. Open it — no build step needed!
# Option A: just open the file
start index.html        # Windows
open index.html         # macOS
xdg-open index.html     # Linux

# Option B: serve it with a local server
python -m http.server 8000
# then visit http://localhost:8000
```
